KEY HIGHLIGHTS

🧾

Custom PDF Invoices

Fully customizable invoice templates for both Accounting and POS modules. Control font sizes, bold styles, logo alignment, and more from settings.

💳

Previous Credit Display

Shows cumulative Customer Account (credit) deductions from all POS orders on the invoice — accurate running total, not invoice residuals.

🏪

POS Integration

Seamlessly hooks into Odoo POS PaymentScreen. Calculates and stores previous credit at order validation time via JS + backend RPC.

🎨

Configurable Styles

Per-field font size and bold settings via Invoice Report Settings. Applies automatically to PDF output — no code changes needed.

📄

A5 Report Format

Compact A5 invoice format for POS — suitable for thermal or small-format printers in retail environments.

⬇️

PDF Download Button

One-click PDF download directly from the invoice form in Odoo backend. Auto-detects POS vs Accounting and opens the correct template.
